Trailstamp 第一階段便條 API — 契約 v4 —— 契約的權威來源是本 repo 的 docs/api/openapi.yaml，本頁只是它的呈現。 語意規則與完整 curl 範例見 notes.md； color／style 對照表見 style-codes.md（由 iOS 維護）。 兩個 base URL：業務端點打 HapeeTrail 服務（頂層 servers）、 /auth/v1/signup 打 Supabase（該 path 自己的 servers）。 要用「Try it out」請先在右上 Authorize 填入匿名登入拿到的 access_token（Bearer）—— 業務請求不再需要 apikey。
